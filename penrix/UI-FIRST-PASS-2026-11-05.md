# 第一版界面

用户授权由实现者决定审美，先看手机实际成品再改。

采用米白纸面、深绿色强调色，首页含继续阅读卡片和台湾小说网/禁忌书屋两个站点卡片；站点点击直接进入，不再经过模块说明页。底部“阅读/书架”切换，书架点击已有章节恢复阅读。保留Firefox地址栏、标签和菜单。正文页与首页配色一致，提供返回浏览器、目录、原文、上下章。

不新增主题系统、账号同步、推荐服务或配置框架。第一版作品/目录仍使用站点网页，正文处理与原生阅读器沿用已写实现。当前不声称全站已统一为原生界面。

验收：编译安装到K20，查看首页、切换空书架、打开站点，并在真实章节检查正文阅读入口。最终状态和截图记录在Firefox-live工作目录及READING-WORKLOG中。
